# 🚀 Antigravity BetterSessions • Supercharged Sentinel & Multi-Profile Manager

Автономное нативное десктопное приложение на **Rust** (`Tao` + `Wry` WebView2) с интерфейсом **Google Pixel Material You (Material 3)** и выразительной типографикой **Serif (Fraunces)** для полного контроля над Google Antigravity: отслеживание квот в реальном времени, мульти-профили аккаунтов, плавающий HUD-виджет поверх окон, системный трей, калькулятор моделей, очистка дискового кэша и встроенное 1-клик автообновление.

---

## 🌟 Ключевые возможности

### 1. 🔄 Multi-Profile Account Switcher (Мгновенное переключение аккаунтов)
- Сохранение и быстрое переключение между несколькими аккаунтами Google Antigravity без повторного ввода логина и пароля.
- Изолированное хранилище профилей в `%APPDATA%\antigravity-bettersessions\profiles`.
- Полная сегрегация статистики и квот для каждого отдельного аккаунта.

### 2. 🪟 Floating HUD Mini-Widget (Плавающий оверлей поверх всех окон)
- Компактный полупрозрачный виджет поверх всех окон (`Always-on-Top`).
- Живой мониторинг оставшихся процентов Gemini & Claude, скорость расхода токенов за текущую сессию и таймер работы.
- Возможность закрепления/открепления и сворачивания в 1 клик.

### 3. 🔔 Системный трей Windows
- Приложение работает в фоне с минимальным потреблением оперативной памяти (<15 МБ).
- Всплывающая подсказка в трее отображает текущие проценты лимитов в реальном времени.
- Быстрое открытие и скрытие по клику на иконку в системной панели.

### 4. 🧹 Очистка кэша и мусора Antigravity
- Автоматическое сканирование временных файлов логов, дампов, кэша сессий и устаревших артефактов.
- Отображение точного пути и освобождаемого дискового пространства в МБ.
- Безопасная очистка одной кнопкой без риска затронуть активные сессии или пользовательские данные.

### 5. 💡 Model Advisor & Калькулятор токенов
- Сравнительный анализ эффективности всех доступных моделей (Gemini 1.5 Pro/Flash, Claude 3.5 Sonnet, GPT-4o).
- Рекомендации по выбору моделей в зависимости от типа задачи (кодинг, рефакторинг, архитектура, быстрые фиксы).
- Расчет стоимости и прогнозирование расхода квоты.

### 6. ⚡ 1-Click Auto-Updater (Автообновление через GitHub Releases)
- Автоматическая проверка новых релизов в репозитории [Aykasu/AntigravityBetterSessions](https://github.com/Aykasu/AntigravityBetterSessions).
- Индикатор обновления в шапке программы и модальное окно с описанием изменений.
- Технология **Hot-Swap** на Windows: скачивание свежего бинарника, безопасная замена запущенного процесса и мгновенный перезапуск без инсталляторов.

### 7. ⏱️ Лайфтайм квоты и аналитика
- Автоподключение к запущенному языковому серверу Antigravity.
- 5-часовые и недельные лимиты Gemini и Claude с обратным отсчетом секунд до сброса.
- Аудио-оповещение при завершении кулдауна (Web Audio API).
- Аппаратный декодер Protobuf Varints из SQLite для полной статистики токенов по дням и проектам.

## 🎨 Дизайн и эргономика

- **Google Pixel Material You (M3)**: адаптивная палитра, скругления 28px, pill-чипы, плавные переходы.
- **Шрифты**: **Fraunces Serif** (700-900 weight) для крупных статусных цифр и **Plus Jakarta Sans** для интерфейса.

---

## 🚀 Быстрый запуск

Запустите готовый исполняемый файл:
```bat
antigravity-bettersessions.exe
```
или через скрипт `run.bat`.

---

## 🛠️ Сборка из исходников

Требуется установленный [Rust](https://rustup.rs/):
```powershell
# Проверка и сборка в режиме релиза
cargo build --release
```
Готовый легковесный бинарник появится в:
`target/release/antigravity-bettersessions.exe`
